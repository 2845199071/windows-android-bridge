Ping · 给朋友的上手说明
================================

这是什么
--------
手机刚拍的照片/截图/下载的文件，几秒内自动出现在电脑屏幕右侧，
点一下就归档到电脑；电脑上的文件拖进去（或右键）就能发到手机。
支持数据线，也支持同一 WiFi 无线（手机零安装）。

怎么开始（三步）
--------
1. 解压本文件夹到任意位置（别放桌面也行，放哪都能跑）
2. 双击里面的「Ping.exe」
   * 如果 Windows 弹「已保护你的电脑」：点「更多信息」→「仍要运行」
     （程序没买代码签名证书，属正常现象）
3. 看右侧面板左下角状态：
   * 插数据线（最简单）：手机开启「开发者选项 → USB 调试」，插上，
     手机弹「允许 USB 调试」点允许 → 面板变「● USB 已连接」
   * 不想插线：手机开「开发者选项 → 无线调试」，在程序「设置 → 手机连接」
     里按提示填一次配对码即可，以后自动重连

怎么用
--------
* 手机拍张照 → 3 秒内右侧弹卡片 → 点「保存」进电脑的归档目录
* 鼠标停在卡片上可预览大图；一次来很多张时窗口不会撑爆，滚轮往下翻
* 电脑 → 手机：把文件拖进面板底部的虚线框，
  或在文件上右键 →「发送到手机」（需在设置里勾选开启一次）
* 不用时点面板标题栏「⟩」收成小圆点，鼠标移上去就展开
* Ctrl+Alt+M（或 J/K，看日志）随时收起/唤出面板

手机端需要的设置
--------
* USB 方式：开发者选项 → USB 调试（开启一次即可）
* 无线方式：开发者选项 → 无线调试（用之前开着；手机息屏后 WiFi 休眠
  会短暂掉线，点亮屏幕几秒内自动重连，无需重新配对）

常见问题
--------
* 面板一直「未连接」：确认开发者选项开了；无线方式确认手机和电脑
  连的是同一个 WiFi（路由器开了「AP 隔离」则不行）
* 保存的文件在哪：面板「设置」里有归档根目录，默认 D:\手机归档
* 出问题看日志：%LOCALAPPDATA%\s2pc\app.log

系统要求：Windows 10 / 11 64 位。adb 已内置在本文件夹，无需安装。
