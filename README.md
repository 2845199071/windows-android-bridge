# windows电脑到安卓手机端互通（Ping）

手机拍的照片、截的图、存的文件，几秒内出现在电脑右侧的悬浮小窗里，点一下「保存」就归到固定目录。
电脑上的文件拖进小窗，就发到手机指定文件夹。

**手机端零安装**，靠 adb 通道（USB 或无线）直接读写手机文件系统。

> 便携版（解压即用，无需 Python / Android SDK）：
> <https://github.com/2845199071/windows-android-bridge/releases/latest>

## 快速开始

**直接双击 `启动.cmd`** 就能用 —— 它会优先启动打包好的 exe，找不到才回退到源码方式。

首次在别的电脑上跑源码，才需要双击 `install.cmd` 装依赖。

手机端准备：

1. 手机开启开发者选项 → **USB 调试**，插上数据线，手机上点「允许」
   - 想用无线：开发者选项 → **无线调试** → 与电脑配对后，在设置里填 `手机IP:端口`
2. 托盘出现 ⇄ 图标，屏幕右侧出现面板，看到 `● USB 已连接` 或 `● 无线已连接` 就通了

## 打包版

`发布\Ping\` 是打包好的独立程序，**不需要安装 Python，也不需要装 Android SDK**（adb 已内置）。
仓库里不含 `发布/` 和 `.venv/`（体积太大），请用上面的 Release 链接下载便携版，
或在本地运行 `打包.cmd` 自行生成：

| 项 | 值 |
|---|---|
| 体积 | **83 MB**（含自带 adb；PySide6 占 46 MB） |
| 内存 | 107 MB 工作集 / 45 MB 私有 |
| 启动方式 | 双击 `Ping.exe`，无任何窗口，只有托盘图标 |

**发给朋友**：压缩整个 `Ping` 文件夹（约 34 MB 的 zip）发过去，解压后双击 `Ping.exe` 即可。
exe 旁边有《好友上手说明.txt》。第一次运行 SmartScreen 可能提示"已保护你的电脑"
（程序没买代码签名证书），点「更多信息 → 仍要运行」。

打包用项目根目录的 **`打包.cmd`** 一键完成（PyInstaller + 把说明拷到 exe 旁）。
程序按这个顺序找 adb：

1. exe 同目录 / `platform-tools\adb.exe` / `_internal\platform-tools\adb.exe`（打包版自带）
2. 本机 Android SDK 的默认位置（见 `app/config.py`，可改成自己的 SDK 路径）
3. 环境变量 `ANDROID_HOME` / `ANDROID_SDK_ROOT`
4. 系统 `PATH` 里的 `adb`

**重新打包**：

```bash
cd packaging
../.venv/Scripts/pyinstaller.exe app.spec --noconfirm --distpath ../发布 --workpath build
```

大约 35 秒。改完代码记得重打包，`启动.cmd` 才能用上新逻辑。

## 怎么用

**手机 → 电脑**

手机拍张照 / 截个图 / 存个文件，3~15 秒内右侧弹出卡片（缩略图 + 文件名 + 大小）。
- 点「保存」→ 进 `D:\手机归档\<类型>\<日期>\<原名>`
- 点「忽略」→ 卡片消失，**手机上的原文件不动**
- 双击卡片 → 用系统默认程序打开
- **鼠标停在卡片上 0.4 秒** → 左侧弹出大图预览（图片看内容、视频看首帧、文档显示类型图标），移开就消失
- 点「全部保存」→ 一键归完

**文件很多时**

窗口高度封顶在 **466px**（1080 屏的 43%，约 3 张卡）就停止拉伸，超出的卡片用**滚轮往下翻**，
右侧有细滚动条提示还有内容。小屏（比如 1366×768）会自动再收，始终不超过屏幕高度的 45%。

**电脑 → 手机**

两条路，效果一样：
- 把文件**拖进面板底部的虚线框**
- 在资源管理器里**右键 → 发送到手机**（在设置里勾选开启，支持多选）

文件落到手机上设置的目录，默认 `/sdcard/Download/电脑发送/`。
中文名、空格、emoji 都正常，重名自动加 ` (1)`。
自己发过去的不再弹回来（否则会自己通知自己）。

**重启不丢卡片**

上次没点完的卡片，重启程序后会原样恢复（暂存文件还在就恢复卡片；
只有确实丢了文件的记录才会清掉）。手机上的原文件始终不受影响。

**收起面板**

- 点标题栏右侧 `⟩` 手动收起，变成右下角一个 **44×44 的小方点**，上面显示待处理数量
- **鼠标移上去就自动展开**，点一下也能展开（远程桌面/触控板上更稳）
- **自动收起**：鼠标离开后 5 秒自动缩回小方点，秒数可在设置里改（0 = 不自动收）
- ⚠️ **还有没处理的文件时不会自动收起**，等你全部处理完才缩回去 —— 一次来 20 个文件时，
  处理掉一个就缩回去是最烦的

**挪位置 / 调透明度 / 置顶**

- 按住标题栏任意空白处拖动，面板能挪到屏幕任意位置，位置会记住
- 面板挡视线时，设置 →「面板 → 不透明度」调低（35%~100%），背景变透、文字仍清晰
- 想回原位点「复位位置」；如果换了显示器/分辨率导致位置跑到屏幕外，会自动回右上角
- **长期没开机不灌积压**：离线超过 12 小时再启动时，只同步**最近 1 小时**的文件
  （不会把攒了十天的全弹出来）；更早的文件仍在手机上——设置里「补拉旧文件」填小时数
  点「开始补拉」就能找回
- **卡片有 3 天时效**：弹出后 3 天没处理（保存/忽略都没点）就自动按忽略处理，
  暂存文件一并清掉，不会白占磁盘；手机上同路径文件之后有新版本会正常重新弹出
- **默认不置顶**：切到别的全屏应用时面板会被正常盖住，不挡事
- **暗夜模式**：点标题栏的月亮图标（或设置 →「深色模式」）整面板变深色，晚上不刺眼；
  再点太阳切回浅色。选择会记住，预览弹窗和设置窗口一起跟随
- 想让它一直浮在最上层：点标题栏的**图钉图标**——平时是灰色轮廓，点一下变白色实心
  （蓝底）= 已固定置顶，状态会记住，重启保持；再点一下取消

## 归档规则

```
├─ 图片\2026-10-30\Screenshot_xxx.jpg
├─ 视频\2026-10-30\MVIMG_xxx.mp4

```

要改目录不用编辑配置文件——点面板标题栏的 **⚙**，见下面「设置」。

## 无线调试（不用插线）

配对一次，以后自动连。**不用记 IP、不用记端口**——Android 11+ 的无线调试会通过 mDNS 广播自己，程序能自动发现并连上；手机换 WiFi、IP 变了都不影响。

### 首次配对

1. 手机：设置 → 更多设置 → 开发者选项 → **无线调试** → 打开
2. 手机：点「**使用配对码配对设备**」，弹出六位配对码和一个 `IP:端口`
   > ⚠️ 这个「配对地址」和无线调试主页显示的 `IP:端口` **不是同一个**，这里要用弹框里的那个
3. 电脑：面板 **⚙ → 手机连接**，把地址和配对码填进去，点「配对」
4. 配对成功后会自动连上，之后不用再配对

### 日常使用

- 手机开着「无线调试」，程序启动就会自己连（通常几秒内）
- 断线后程序每 5 秒自动重试，不用管；也可以点设置里的「刷新」
- **手机重启、或手动关掉无线调试后，需要重新打开那个开关**，但不用重新配对

### 如果连不上

| 现象 | 处理 |
|---|---|
| 一直显示「未连接」 | 确认手机「无线调试」开关是开的、WiFi 连着、和电脑同一网段 |
| 配对报错「配对码过期」 | 手机上重新点一次「使用配对码配对设备」，配对码有时效 |
| 之前能用，突然断了 | 手机息屏导致 WiFi 休眠。点亮屏幕重新打开无线调试；程序会自动重连 |
| 同一 WiFi 但连不上 | 路由器可能开了「AP 隔离」，关掉它，或换手机热点 |

无线实测：扫描一轮 1.8 秒（USB 约 1.2 秒），拉取 8MB 约 14 MB/s，推送约 4 MB/s。日常够用。

## 设置

点面板标题栏的 **⚙**，或托盘菜单 →「设置…」：

- **电脑 → 手机 发送目录**：拖进悬浮窗的文件存到哪。
  可以直接输入路径；点「浏览手机…」能逐级点进手机文件夹去选；
  4 个快捷按钮（下载 / 相机 / 图片 / 文档）一键跳过去，你自己加的末级子目录名会保留。
- **手机 → 电脑 归档根目录**：点「浏览…」用系统的文件夹选择框。
- **扫描间隔**：常用目录（拍照截图那些）默认 3 秒，其他目录默认 15 秒。
- **连接方式**（手机连接区）：
  - **自动连接**（默认）：息屏掉线后自动重连，点亮屏幕几秒就回来；
  - **手动连接**：不主动连——未连接时面板标题栏出现「连接」按钮，点了才连。
    适合不想让程序一直在后台找手机的场景。

保存后**即时生效，不用重启**。改过发送目录后，旧目录会自动进排除表——里面之前发过的文件不会突然弹出来让你确认（它们本来就是你发过去的）。

## 监听哪些目录

| 频率 | 目录 |
|---|---|
| 3 秒 | `/sdcard/DCIM`（相机/截图）、`/sdcard/Pictures`、`/sdcard/Download`、`/sdcard/Documents` |
| 15 秒 | `/sdcard/Screenshots`、`Movies`、`Music`、QQ 的 `QQfile_recv`、微信的 `MicroMsg/Download` |

**刻意不监听**：微信 `MicroMsg/<hash>/image` —— 那里是加密 `.dat`，拉出来打不开，而且有上千个子目录（实测扫一遍 5.4 秒）。

## 已知限制

- **依赖 adb**：手机必须开 USB 调试。无线调试在手机重启后可能要重新点一次开关。
- **靠文件 mtime 判断新旧**：如果有 App 把老文件复制进手机（保留了原始时间戳），可能漏掉。照片/截图/下载/“保存到手机”这些常见场景都是当前时间，不受影响。
- 只支持 Windows + 单台手机。
- 视频首帧/Office 缩略图依赖系统的缩略图处理器，没有就回落到类型色块。

## 全局热键

**Ctrl+Alt+M** 收起/唤出面板；如果这个组合被别的软件占用（不少工具都爱用 M），
程序会自动顺延到 **Ctrl+Alt+J → Ctrl+Alt+K**，实际生效的组合写在日志里。
托盘菜单和双击托盘随时也能切换。

## 排错

| 现象 | 处理 |
|---|---|
| 面板显示「未连接」 | `adb devices` 看设备在不在；不在就重插线、手机上重新点「允许」 |
| 手机上有文件但没弹窗 | 看 `%LOCALAPPDATA%\s2pc\app.log`；确认文件在监听的目录里、扩展名不在排除表（`.tmp/.dat/.part` 等） |
| 中文名文件发送失败 | 已修（先推 ASCII 临时名再在手机端 mv 回原名），若仍有问题看日志里的 adb 报错 |
| 托盘图标消失 | 任务管理器结束残留 `pythonw.exe`，重新双击启动 |

日志：`%LOCALAPPDATA%\s2pc\app.log`
数据：`%LOCALAPPDATA%\s2pc\data.db`（快照/待处理/归档记录）
暂存：`%LOCALAPPDATA%\s2pc\staging`（保存或忽略后自动清）

### 两处省资源的做法（都不是猜的，有实测）

**1. 扫描走常驻 `adb shell -T`，不每次起新进程。** 每次 `adb shell` 光进程创建
加与本机 adb server 握手就要 60~70ms（`adb version` 中位 70.6ms），而监听器每 3 秒
扫一轮。改成一条常驻会话后，真机实测同一套 `find` 从 **180ms 降到 63ms**，
每轮省 117ms。协议是「命令 + `echo <随机哨兵>`，读到哨兵算结束」，带超时和
自动重建；会话一旦异常就退回一次性进程，功能不受影响。

**2. SQLite 用 WAL + `synchronous=NORMAL`，水位线合成一次事务写。**
每轮要推进 4~7 个目录的水位线，默认配置下每次提交都 fsync。实测单条写入
0.029ms → 批量 0.001ms/条。

### 结构

| 文件 | 职责 |
|---|---|
| `app/config.py` | 默认配置、目录白名单、类型分类 |
| `app/adb.py` | adb 通道（设备发现、shell、pull、push） |
| `app/store.py` | SQLite（快照 diff、待处理、归档、忽略） |
| `app/watcher.py` | 分层轮询调度，产出新文件事件 |
| `app/puller.py` | 拉取线程 |
| `app/archiver.py` | 归类归档、重名处理 |
| `app/thumbs.py` | 缩略图（图片/PDF/色块） |
| `app/dock.py` | 右侧悬浮面板 |
| `app/main.py` | 装配 + 托盘 + 发送 |
